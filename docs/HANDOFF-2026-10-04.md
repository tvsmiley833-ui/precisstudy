## What the site is
precisstudy.com: free study guides for high school and AP students (57 guides), plus quizzes, flashcards, practice exams, dashboard, planner, settings, compete, study tips. Cloudflare Worker with static assets (`run_worker_first`), KV (PROGRESS, MAGIC_LINKS, FEEDBACK, GUIDE_REQUESTS), HTMLRewriter widget injection, crons.

## Daily workflow
```
npm test                      # vitest (workers pool) + node tests; must be green (736 tests)
npm run typecheck
npm run guides:regen          # rebuild generated guide pages (+ class-counts.json)
node scripts/sync-home-counts.mjs
node scripts/generate-tips.mjs [--check]
npm run build:client          # client/*.js -> public/shared/*.js (minified)
npm run deploy                # predeploy runs tips, lastmod, client build, typecheck, tests; ends with a smoke check
```
- Never hand-edit generated pages (`public/<guide>/index.html`, `public/tips/**`). Edit `guides/*.json`, `tips/*.json`, `scripts/guide-template/*`, `scripts/generate-guide.mjs`, `scripts/generate-tips.mjs`, then regenerate.
- Editing `client/guide-app.js` or `client/personality.js` needs `npm run build:client`.
- Don't chain with `;` after a command that might fail: a `;` once deployed over a failing test.
- After editing a shared file, restart the dev server (hashes are cached per isolate) and add a `?x=` query to dodge the service worker.
- JSON round-trip (indent 1, `ensure_ascii=False`) is byte-stable for all guide files.
- Test files that read files go in `test/*.node.test.mjs` (the workers pool has no `fs`).
- Don't export string constants from `src/worker.ts` (crashes `wrangler dev`); put them in a module such as `src/mission-banner.ts`.
- GateGuard hooks sometimes ask for "facts" before the first Bash or a new file: state the request, what the command does, and retry.

## Architecture notes that are easy to miss
- **Plan model:** `public/shared/plan.js` (`window.ssPlan`) owns exams. `ss-exams` (list: id, date, label, slug) is the source; `ss-exam` always mirrors the nearest upcoming exam for older readers (homepage, guides, dashboard). A signed-in student's goal (`/api/goal`: days, minutesPerDay) is synced from it. `planner-page.js` drives `/planner/`; the weekly builder and assignments live in `dashboard-app.js`. Class sizes come from `public/shared/class-counts.json` (generated).
- **XP and level:** one curve everywhere; quest XP now counts in `computeServerXP` (src/progress-routes.ts) and the dashboard's `computeXP`. `/api/stats` returns streak, XP, level.
- **Streaks:** `src/streak.ts`: `effectiveStreak`, `nextStreak` (freeze earned every 7 days, max 2, covers one missed day).
- **Sessions:** signed cookie with `sid`, `av`, `name`; revoked ids live in `sv:<email>` KV value.
- **Page ETags** include a deploy id (`CF_VERSION_METADATA`), so a deploy forces fresh rewritten pages.
- **Shared scripts** listed in `SHARED_JS_FILES` (src/worker.ts) get `?v=<hash>` rewrites; new shared files (plan.js, plan.css, planner-page.js, dialog.js) are in that list. `dialog.js` (`ssConfirm/ssAlert/ssPrompt`) is injected on every page.
- **Guides:** saved syllabus order is applied inline before render (generator) and the units/chips are rebuilt when it differs from the prerendered order (`client/guide-app.js`). One shared `/api/progress` request per guide load (`ssProgressOnce`).
- **CSP** `img-src` blocks `blob:`; avatar resize uses `createImageBitmap`.
- **Brand:** bookmark-notch P mark; Forest palette (green #1f6e46, amber #f5b83d, cream #fff3c9). Dark mode logo has a white bookmark (`.mb{fill:#fff}`); the favicon is the full mark with no white box.
