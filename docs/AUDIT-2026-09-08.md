# PrecisStudy Audit — 2026-09-08

Five-lens review (ECC skills/agents): TypeScript, security, SEO, accessibility, repo/production health.
Backend is ~1,915 lines of TS across 8 files, 214 tests, Cloudflare Workers + KV, no CI.

## Fixed and committed (pending `npm run deploy`)

| # | Area | Change |
|---|------|--------|
| 1 | Security HIGH | `/api/chat` now rate-limited per IP (20/min via PROGRESS KV) and CORS scoped to the 4 site origins instead of `*`. Was an open, unmetered LLM proxy billable to the account. |
| 2 | Security MED | `verifySession` rejects tokens with a `purpose` field (OAuth-state tokens share the signing secret) and tokens with no string `email` (previously became `email: undefined` in KV keys / admin checks). |
| 3 | TS/robustness | `checkRateLimit` NaN bug — a non-numeric KV value no longer permanently disables that limiter key. |
| 4 | TS/robustness | `worker.fetch()` wrapped in try/catch → unhandled errors now return 500 with security headers, not Cloudflare's bare response. |
| 5 | Security MED | `handleEmailStart` gains a per-IP cap (10/h) on top of the per-email cap → stops magic-link mail-bombing of enumerated addresses. |
| 6 | SEO CRIT | `/sitemap.xml` served dynamically from `SUBJECT_PATHS` (was a static file listing 17 of 50+ routes). Static file deleted. |
| 7 | SEO MED | Canonical 301 normalises `/subject` -> `/subject/` (one hop, not 301->308) and sets `Cache-Control: max-age=86400`. |
| 8 | SEO MED | `robots.txt`: removed `Disallow: /dashboard` + `/settings` (they have `meta noindex`; the disallow was hiding the noindex from Google); added `/auth/`, `/onboarding`. |

Tests updated for scoped CORS; added sitemap + path-normalisation cases. 216 tests, all green; typecheck clean.

## Not fixed — needs your call

### Backend / security (mostly small, low-risk — good for a follow-up pass)

| Sev | Item | Fix |
|-----|------|-----|
| MED | Login CSRF via `GET /auth/verify` — an attacker's magic link, if opened by a victim, logs the victim into the attacker's account. | Serve an interstitial that POSTs the token same-origin, or bind the token to a cookie set at `handleEmailStart`. |
| MED | Sessions can't be revoked — stateless 30-day HMAC token; "log out" only clears the cookie. | Add a per-user `sessionVersion` in KV, include + check it in `verifySession`; bump on logout-all. |
| MED | No CSRF defense-in-depth on authed `POST /api/*` — relies solely on `SameSite=Lax`. | Central `Origin` / `Sec-Fetch-Site: same-origin` check for non-GET `/api/*` + `/auth/*`. |
| MED | Unbounded progress-blob writes — `mastery`/`examples` accepted as any object, rewritten on every progress/goal/streak/push call and iterated by 3 crons. | Cap serialized size (~32 KB), cap `cardsKnown.length`, validate `{correct,total}` shape. |
| MED | Admin file download reflects client-set `Content-Type` from public upload metadata. | Force `application/octet-stream` on the download response. |
| MED | Shared HMAC secret for session + OAuth-state tokens. | Separate secrets (partly mitigated by fix #2). |
| MED | N+1 KV `get()` in push-cron and admin-stats loops. | `Promise.all` per `list()` page. |
| LOW | OAuth `.json()` results typed `any`; `recordLogin` 500s on a malformed existing record; `getClientIp` returns `"unknown"` (shared bucket) when `CF-Connecting-IP` absent; `json()` reimplemented in 6 files; two `SUBJECTS` lists disagree (`chat.ts` `ap-lang` vs `progress-routes.ts` `aplang` + calc keys); CSP keeps `'unsafe-inline'` in `script-src`. |

### Production / ops

- No CI. 214 tests + typecheck exist but nothing runs them on push; deploy is manual. Add a GitHub Actions workflow (`npm ci && npm run typecheck && npx vitest run`) gating `main`. The repo has ECC's `*-with-strix` skills for pre-merge security scanning too.
- No error monitoring — one `console.error` in the whole backend. Add a Workers Tail consumer or Sentry.
- No health check endpoint verifying KV/AI reachability.
- No env documentation — add `.dev.vars.example` listing `SESSION_SECRET`, `GOOGLE_CLIENT_SECRET`, `GITHUB_CLIENT_SECRET`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` (all `wrangler secret put`).

### Accessibility — all template-level (one guide template -> all ~38 guide pages)

| Sev | Item |
|-----|------|
| HIGH | Flashcard flip is a mouse-only `<div onclick>` — not keyboard operable (WCAG 2.1.1). Make it a `<button>` + `aria-live` for the revealed face. |
| HIGH | Tab UI has no `role="tablist/tab/tabpanel"`, `aria-selected`, `aria-controls`; activating a tab moves no focus. Implement the APG Tabs pattern. |
| HIGH | Unlabeled controls on guide pages (planner sliders, `#search-box`, `#fc-sel`, `#q-sel`) — homepage does these right, template regressed. |
| HIGH | No landmarks (`<main>`/`<nav>`) and no skip link on guide pages. |
| HIGH | Quiz correctness is colour-only; dynamic updates (score, explanation, search count, combo banner) never announced — no `aria-live` anywhere. Reduced-motion users get no streak feedback. |
| MED | Broken heading hierarchy; keyboard gaps in search rows / accordion / exam headers; target size < 24x24 (2.5.8); contrast fails on tier pills + `--ink-dim`; no `prefers-reduced-motion` on guide pages. |
| LOW | Decorative SVGs missing `aria-hidden`; toggles missing `aria-pressed`/`aria-expanded`; mobile menu misuses `role="menu"`. |

Positives: homepage already has skip link, landmarks, labelled sliders, reduced-motion CSS, motion-gated confetti; backend has strong test coverage, correct secret separation, OAuth-state CSRF protection, push SSRF allowlist, admin authz, no open redirects, constant-time session verify, prototype-pollution-aware `SUBJECTS`.
