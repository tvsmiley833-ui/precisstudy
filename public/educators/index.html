Educator Resource Hub

A class code, a roster, and a printable index of every subject's reference sheets and practice exams -- built on the same Study Group tools students already use.

How it works
1 Create a class code below (this reuses PrecisStudy's existing group-create flow -- a class code is a Study Group code). There's no separate "teacher account" -- anyone can create one and it's yours to manage.
2 Share the code with your class. Students join at /study-group or /leaderboards -- they only need to opt in and enter the code. Only an anonymous handle is ever shown, never a real name or email.
3 Come back here (or to /study-group) to see the roster and the group's weak-spots aggregate -- which units your class is collectively struggling with most, without seeing any one student's individual answers.
