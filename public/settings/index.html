Connect Canvas to pull your assignments into the same list as Google Classroom.

An access token works like a password for your Canvas account, so treat it that way. In Canvas, open Account → Settings → New Access Token, give it a purpose like “PrecisStudy” and an expiry date a few months out. We only use it to read your upcoming assignments, we store it encrypted, and you can disconnect here (and delete the token in Canvas) any time.

Generate a token from Canvas: Account → Settings → "+ New Access Token".
